# DMS PiBurger

Aplicativo Flutter para cardápio digital e pedidos de restaurante. O projeto inclui cadastro e login, categorias de produtos, detalhes com descrição e preço e um carrinho de compras.

## Tecnologias

- Flutter e Dart
- Provider para gerenciamento de estado

## Executar localmente

Requisitos: Flutter SDK instalado.

\`\`\`bash
flutter pub get
flutter run
\`\`\`
